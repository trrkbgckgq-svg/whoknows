# Security

Found a bug that could put anyone's funds at risk? Please report it privately first.

- Use GitHub's **Report a vulnerability** button on this repository's Security tab, or
- Send a direct message to [@Whoknowsitteam](https://x.com/Whoknowsitteam) on X saying you have a
  security report, and we'll set up a private channel.

Please include what you found, the steps to reproduce, and what an attacker could gain. Please
don't test against live markets with real users' funds.

We'll confirm we got your report, keep you updated, and credit you publicly once it's fixed if you'd
like.
